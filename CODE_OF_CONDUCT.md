# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Everyone who takes part (in issues, pull requests, discussions and any other project space)
is expected to follow it.

In short: be kind, be patient, assume good intent, and keep criticism about the work, not the
person. Harassment of any kind is not tolerated.

To report unacceptable behaviour, contact the maintainer, @sabalys-ramunas, through
[their GitHub profile](https://github.com/sabalys-ramunas), or open an issue when the matter
can be public. For something that should stay private, an issue that asks for a private
channel, with no details, is enough. Reports are handled in confidence, as the Covenant's
enforcement guidelines describe.
